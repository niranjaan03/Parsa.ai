// FREQUENTLY ASKED QUESTIONS

Common Questions

How does the 3-Layer Extraction strategy save up to 90% on LLM costs?
Instead of sending every document directly to an expensive LLM, our pipeline first attempts Layer 1 (regex & anchor template rules) and Layer 2 (lightweight NER models). Over 94% of standard forms are processed cleanly in Layers 1 & 2 at zero LLM cost, escalating to Layer 3 LLMs only when confidence drops below your configured threshold.
Can I use my own custom LLM API keys (OpenAI, Anthropic, Gemini, Ollama)?
Yes! You can configure your custom keys directly on our API Keys Page. You can choose OpenAI (GPT-4o), Anthropic (Claude 3.5 Sonnet), Google Gemini, or local self-hosted Ollama / vLLM endpoints.
What file formats are supported?
Our platform supports PDF, PNG, JPEG, TIFF, BMP, WebP, ZIP archives, and email MIME documents. Scanned PDFs and images are processed using Unlimited-OCR VLM, while native digital PDFs bypass OCR for maximum speed.
Can I deploy the platform on my own private cloud / GPU servers?
Yes. We provide complete Docker Compose and Kubernetes Helm manifests to deploy the entire 9-stage IDP pipeline inside your private AWS, GCP, Azure, or on-prem GPU cluster with zero external data egress.

End-to-End 9-Stage Orchestration

From raw upload to HMAC-SHA256 signed webhook delivery across 9 micro-orchestrated stages.

STAGE 01

Secure Ingestion

Magic-byte validation, ClamAV virus scanning, zip-bomb defense, and SHA-256 idempotency check.

STAGE 02

Document Profiling

Detects digital PDFs to skip OCR entirely, scores scan quality, and selects image enhancement filters.

STAGE 03

Pre-Processing & Layout

De-skew (0.4° precision), adaptive binarization, denoise, and 5-class layout region segmentation.

STAGE 04

Unlimited-OCR Router

Runs Unlimited-OCR (3B-MoE VLM, gundam 640 crop) via SGLang RadixAttention prefix caching.

Normalization Engine

Converts dates to ISO-8601, normalizes currency values, and cleans CJK/special characters.

STAGE 07

Math & Trust Scoring

Arithmetic verification ($Subtotal + Tax = Total$), fraud signature checks, and composite TrustScore calculation.

Decision Engine
